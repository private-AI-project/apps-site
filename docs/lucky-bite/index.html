Lucky Bite
사다리타기·돌림판·제비뽑기

누가 당첨인지, 누가 먼저 할지, 팀은 어떻게 나눌지 고민될 때 'Lucky Bite'로 바로 해결해요.

App Store에서 받기
01

주요 기능

  • 참가자 이름과 사진을 직접 등록해요. 내 사진첩에서 바로 가져올 수 있어요.
  • 자주 쓰는 모임 명단은 프리셋으로 저장해두고 빠르게 불러와요.
  • 모든 게임 결과는 카드로 만들어 친구들과 공유할 수 있어요.
02

모임용 뽑기 게임 21종

  • 돌림판: 프리셋 참가자 이름으로 칸이 만들어져 바로 돌려요.
  • 사다리타기: 당첨 개수를 정하고, 섞인 결과 카드 아래로 한 명씩 또는 한 번에 내려가요.
  • 제비뽑기: 컵에서 차례로 제비를 뽑고, 끝 색으로 당첨을 모두가 확인해요.
  • 동전 던지기: 별/달, 서바이벌 모드로 분위기 전환.
  • 경마 레이스: 참가자마다 캐릭터(또는 사진)가 한 명씩 달려요.
03

모임 도구

  • 자리 배치: 원탁·긴 테이블·교실·자유 자리판을 만들고 자리를 옮겨가며 배치해요.
  • 배정 방식: 랜덤 배정 또는 게임 순서로 1등부터 자리를 고르는 방식을 선택해요.
  • 프리셋을 무제한으로 저장할 수 있어요. 모임이 많아도 걱정 없어요.
  • 프리셋별 1위, 꼴찌, 당첨 기록을 남겨서, 누가 얼마나 많이 걸렸는지 알 수 있어요.
  • 공정 모드로 최근 많이 당첨된 사람의 확률을 낮춰줘요.
